# Synthetic demo volumes

These three `.nii.gz` files are **synthetic phantoms**, generated for interface
testing only. They are not patient scans and must not be used for clinical
interpretation.

They replace the original OASIS-derived sample volumes, which are governed by
the OASIS data-use agreement and should not be redistributed in a public
repository.

If you need a realistic demo, download OASIS or ADNI data yourself after
accepting the relevant data-use agreement, and keep it outside Git.
