# NeuroDetect Lite - Frontend

This is the React-based frontend for the NeuroDetect Lite application.

For a full project overview, architecture diagrams, and system screenshots, please refer to the **[Root README](../README.md)**.

## Local Development

1. **Install dependencies**:
   ```bash
   npm install
   ```

2. **Run the app**:
   ```bash
   npm run dev
   ```

3. **Check environment variables**:
   Ensure you have a `.env.local` file configured with the correct backend API URL.
